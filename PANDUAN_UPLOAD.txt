PANDUAN PEMASANGAN WEB MONITOR POS (pos.shinemart.id)
=====================================================

Folder `pos-shinemart-web` ini berisi halaman web statis mobile-friendly
(HTML + CSS + JavaScript) untuk memantau & mengelola cabang ShineMart dari HP.

LANGKAH 1 — Siapkan Key di `config.js`
1. Buka file `pos-shinemart-web\config.js`.
2. Pastikan `SUPABASE_URL` sesuai dengan Project URL Anda:
   https://sspafsuypniwbzzbvlfq.supabase.co
3. Isi `SUPABASE_KEY` dengan Publishable Key (`sb_publishable_...`) atau
   Legacy Anon Key (`eyJ...`) dari Dashboard Supabase -> Settings -> API Keys.
   (JANGAN pernah memakai Secret Key `sb_secret_...` di file web ini!)

LANGKAH 2 — Buat Akun Login Owner di Supabase Auth
1. Di Dashboard Supabase, buka menu Authentication -> Users.
2. Klik "Add user" -> "Create new user", isi Email & Password untuk login dari HP,
   centang "Auto Confirm User".
3. Di Authentication -> Sign In / Providers -> User Signups, matikan opsi
   "Allow new users to sign up" agar orang lain tidak bisa mendaftar akun sendiri.

LANGKAH 3 — Upload ke Subdomain pos.shinemart.id
1. Buka File Manager hosting / cPanel subdomain `pos.shinemart.id`.
2. Upload ke-4 file utama berikut ke folder root subdomain `pos.shinemart.id`:
   - index.html
   - styles.css
   - app.js
   - config.js
3. Buka https://pos.shinemart.id dari browser HP Anda lalu login dengan akun
   Supabase Auth yang dibuat pada Langkah 2.

CARA KERJA EDIT PRODUK & UBAH STOK DARI HP
- Setiap kali Anda mengubah harga, menambah produk, atau melakukan mutasi stok
  (Restock / Opname / Waste) dari HP, perintah masuk ke antrean `cloud_remote_commands`.
- PC kasir cabang yang menyala otomatis mengeksekusi perintah tersebut pada siklus
  Cloud Sync berikutnya (atau saat klik "Sync Sekarang"), mencatatnya ke Kartu Stok
  & Audit Log lokal, lalu mengirim saldo stok terbaru kembali ke layar HP Anda.
